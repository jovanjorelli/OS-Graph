## 🌌 Overview

**OS-Graph** models the complete genealogical lineages, structural bifurcations, and architectural mutations of operating systems from early mainframes to modern microkernels.

Spanning 816 curated individual systems and 696 directed evolutionary relationships, the platform reconstructs Unix, BSD, Linux distributions, Windows/DOS, macOS/Darwin, and independent academic research platforms. It calculates Lowest Common Ancestors (LCA) across disparate trees, analyzes instruction set architecture (ISA) overlaps, and aggregates multi-regional historical dossiers with zero external backend dependencies.

## 🏛️ Core Architecture

### 🪐 Spatial Graph Engine
- **Spatial Hash Grid Indexing**: $O(1)$ uniform coordinate hash grid delivering instant cursor hit-testing across thousands of nodes without linear search overhead.
- **Frustum-Aware Canvas 2D Pipeline**: Dynamic culling of off-screen nodes and subpixel labels with pre-rasterized glyph caching.
- **3D Atmospheric Celestial Globes**: Glowing planetary atmosphere backdrops, limb glows, and tilted orbital equator rings rendered per family cluster.
- **Lineage Vector Filaments**: Directed particle animations rendering parent-to-derivative heritage pathways and evolutionary momentum.
- **Adaptive Precision Zoom**: Multi-tier level of detail (LOD) scaling smoothly from galaxy-wide macro topologies down to individual distribution specs.

### 🧬 Phylogenetic Kinship & LCA Analysis
- **Lowest Common Ancestor (LCA)**: Resolves the exact convergence milestone uniting any two systems in the genealogical graph.
- **Lineage Distance Trace**: Interactive step-by-step breadcrumbs detailing generation counts and generational disparities between subjects.
- **Temporal Delta Computation**: Real-time evaluation of inception epoch gaps and technological eras.
- **One-Click Subject Inversion**: Instant bidirectional role-swapping with complete recalculation of comparative matrices.

### 🌐 Multi-Regional Intelligence & Media
- **12 Supported Locales**: Seamless runtime localization for English (US), English (UK), Russian, Ukrainian, German, French, Spanish, Portuguese, Arabic, Japanese, Chinese, and Hindi.
- **Multi-Source Media Aggregation**: Cross-queries international Wikipedia and Wikimedia repositories with redirect resolution and icon filtering, assembling authentic screenshot albums.
- **Dedicated Loading Skeleton State**: High-fidelity cyberpunk loading cover with animated pulse indicators and spinner for asynchronous Wikipedia dossier retrieval.
- **Gesture Lightbox**: Fullscreen modal viewer featuring spring pan/zoom, boundary constraints, and backdrop blur.

### 📊 Architectural Spec Matrix
- **Side-by-Side Taxonomy Comparison**: Direct evaluation of kernel architectures (`Monolithic`, `Microkernel`, `Hybrid`, `Exokernel`), phylogenetic families, licensing terms, and encyclopedic prominence.
- **Processor ISA Hardware Overlap**: Quantitative computation of target CPU architecture intersections (`x86-64`, `ARM`, `RISC-V`, `MIPS`, `PowerPC`, `s390x`) highlighting shared and platform-exclusive support.

### 🔍 Curated Historical Dataset & Filtering
- **Curated Notable Systems (816 Systems)**: Rigorously filtered to notable distributions, foundational progenitor platforms, and prominent regional systems with unbroken lineage continuity.
- **Volumetric Spherical Orbs ("Шарики")**: Family constellations structured as cohesive 3D spherical balls using continuous area-weighted radial shells and golden-angle phyllotaxis, radiating from progenitor roots ("мама") through successive generations ("сын", "внук") with depth-based shading and specular highlights.
- **Temporal Timeline Scrubbing**: Interactive chronological range selector spanning 1950 to present day (fully preserving foundational 1950s–1960s systems like GM-NAA I/O, BESYS, CTSS, GCOS, and OS/360).
- **Sub-Millisecond Search**: Fast fuzzy matching indexing system titles, developers, kernel models, and launch dates.

## ⚠️ Historical Data Notice & Genealogical Precision

The operating system phylogenetic graph is synthesized from encyclopedic archives (Wikidata, Wikipedia), academic retrospectives, UNIX genealogy charts, and open distribution records spanning over seven decades of computer science history (1950–Present).

Due to the decentralized, multifaceted, and evolving nature of software engineering history:
- **Historical Approximations**: Inception years, kernel architectural classifications, and primary progenitor assignments represent established historiographical consensus. Individual academic or corporate sources may occasionally record divergent dates (e.g. project inception vs. initial public announcement vs. commercial availability).
- **Multi-Parent & Hybrid Influences**: Many modern operating systems synthesize components from disparate lineages (such as GNU userland tools, BSD network stacks, Mach microkernels, or hybrid abstraction layers). The primary displayed links model direct architectural or distribution parentage to preserve a legible phylogenetic tree.
- **Reporting Inaccuracies & Community Corrections**: If you encounter an imprecise date, a disputed classification, or an overlooked historical milestone, community corrections are warmly welcomed! Please open an issue or submit a pull request with authoritative historical citations on GitHub.
